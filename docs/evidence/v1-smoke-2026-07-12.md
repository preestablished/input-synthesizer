## Cross-repo seam noted

`SynthBringup` verifies the experiment config's `macro.packs` entries against
`Health.loaded_packs`, which carries content-hash **pack ids** — so configs
consumed by the orchestrator must reference packs by id, not name (API.md §5.6
allows either; the synthesizer's resolver accepts both). Worth a line in the
orchestrator's docs or a future API.md clarification; raised in the
resolution.
